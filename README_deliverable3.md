# MSCS-634 Project: Deliverable 3 - Model Evaluation and Optimization

## 📌 Project Overview

This phase of the project focuses on **evaluating the performance of multiple regression models** trained on the heart disease dataset. Models from Deliverable 2 are analyzed, and enhancements like confidence intervals, residual analysis, and actual vs predicted scatter plots are incorporated.

---

## 📁 Files Included

| Filename                      | Description |
|------------------------------|-------------|
| `cleaned_heart_disease.csv`  | Cleaned dataset used for training and evaluation |
| `MSCS-634-Project-Deliverable3.ipynb` | Jupyter notebook with full code, analysis, and visualizations |
| `requirements.txt`           | Python packages required to run the notebook |
| `README_deliverable3.md`     | This README file |

---

## 🧠 Models Evaluated

- Linear Regression
- Ridge Regression
- Lasso Regression

These models were evaluated using multiple metrics and visualization techniques.

---

## 📊 Evaluation Metrics Used

- **MAE (Mean Absolute Error)**
- **MSE (Mean Squared Error)**
- **RMSE (Root Mean Squared Error)**
- **R² (Coefficient of Determination)**
- **Cross-Validation R²**
- **95% Confidence Intervals for CV R²**

---

## 📉 Visualizations Included

- Residual plots for all models
- Actual vs Predicted scatter plots
- Tabular comparison of evaluation metrics

---

## ✅ Enhancements Added

- Re-scaling and re-encoding of data before model evaluation
- Confidence intervals for CV scores (95% CI)
- Interpretation of plots and metrics in markdowns
- Model comparison and performance commentary

---

## 🧪 Tools & Libraries Used

- Python 3.13
- Pandas, NumPy, scikit-learn, matplotlib
